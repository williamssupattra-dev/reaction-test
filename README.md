# Reaction Time Test

A simple beginner's cognitive science experiment that measures how fast you react to a visual signal.

**Click to Begin:** [Live demo](https://williamssupattra-dev.github.io/reaction-test/)

## How it works
- Click the box to start
- Wait for the electric-blue glow (randomized 1–3 second delay)
- Click as soon as you register the glow
- Clicking TOO early resets the round
- After 5 tries, it shows your average in milliseconds

## Why
Reaction time matters in neuroscience because it acts as a direct, measurable window into central nervous system processing speed, neural efficiency, and brain health.
